# The Rock Bench — Benchmark Reproduction Procedure
# ai-memory-benchmark

## Step 1 — Save the Original Text
1. Copy the original source text from the benchmark dataset.
2. Open a new chat in the system being tested.
3. Paste the original text into the chat.
4. Press Enter and wait for the text to finish loading.
5. Click **Save** at the bottom of the chat to store the original text.

## Step 2 — Run the Recall Test
1. Open a completely new chat.
2. Copy and paste the benchmark prompt into the chat.
3. Press Enter.
4. Wait for the system to generate its response.

## Step 3 — Submit the Results to The Rock Bench
1. Copy the complete response generated by the system.
2. Open **The Rock Bench — Deterministic Check**.
3. Paste the generated response into the result field.
4. Copy the original source text used in Step 1.
5. Paste the original source text into the original text field.

## Step 4 — Verify the Result
1. Click **Analyze** in The Rock Bench.
2. The system performs a deterministic comparison of the original text against the generated response.
3. The benchmark produces a SHA verification key and reports the result as either **VERIFIED** or **UNVERIFIED**.

**The benchmark is complete.** The result is determined by the deterministic verification process, not by an AI judge or subjective assessment.
